Key Constraints

Dynamic App Router paths must be known at build time: dynamic routes with dynamicParams: true or without generateStaticParams() are unsupported under static export. Next.js static export docs
Request-time features are out: cookies(), Server Actions, ISR, Draft Mode, request-dependent Route Handlers, rewrites, redirects, headers, proxy, and intercepting routes are unsupported. Next.js static export docs
