# 5. WHAT APNETAILOR DOES

ApneTailor is a technology-enabled tailoring platform connecting customers with nearby tailors and coordinating the stitching workflow.

The website is customer-facing.

The primary customer journey in the app is conceptually:

1. choose a supported garment category;
2. provide measurements;
3. sign in;
4. provide tailoring details and notes;
5. select relevant garment options;
6. specify whether the customer or tailor provides the fabric;
7. provide fabric information and, where applicable, fabric imagery;
8. optionally provide reference imagery;
9. provide location/address information;
10. nearby relevant tailors are informed about the opportunity;
11. interested tailors may provide price and expected completion date;
12. the customer reviews relevant information;
13. the customer pays;
14. logistics depend on who provides the fabric;
15. if the customer provides the fabric, pickup transports it to the tailor;
16. if the tailor provides the fabric, that initial pickup step is unnecessary;
17. the tailor performs the stitching workflow;
18. progress imagery is provided during the workflow;
19. the customer can review progress and, where supported by the actual app workflow, request changes;
20. users receive relevant status updates;
21. users can communicate through the supported chat functionality;
22. pickup/delivery logistics can be tracked where applicable;
23. the finished garment is delivered to the customer;
24. the order is completed.

The website should explain the customer value of this workflow clearly without exposing proprietary implementation details.

Do not publicly expose:

* internal matching thresholds;
* radius-expansion logic;
* exact timers;
* private API architecture;
* database fields;
* internal status values;
* fraud controls;
* security implementation details;
* confidential operational logic;
* internal courier integration details;
* private backend implementation.

Explain benefits, not confidential internals.
